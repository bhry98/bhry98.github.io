# Laravel packages

<p class="bh-lead">Open-source packages I built during my PHP and Laravel years, before focusing fully on
enterprise Java, integration and OpenShift. They are still available on GitHub for anyone who finds them useful.</p>

<div class="grid cards" markdown>

-   :material-api:{ .lg } **Laravel API Response**

    ---

    <span class="bh-tag bh-tag--live">Documented</span>

    A fluent, extensible, highly configurable API response toolkit for Laravel 11, 12, 13 and 14.

    - Standardized JSON envelope & presets
    - Ready-made success & error responses
    - Rate limiting & audit-log middleware
    - Testing helpers, hooks, events & macros

    [:octicons-book-24: Read the docs](../packages/laravel-api-response/index.md){ .md-button .md-button--primary }
    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/laravel-api-response){ .md-button }

-   :material-account-multiple-outline:{ .lg } **Laravel Users**

    ---

    A complete users-management foundation for Laravel.

    - User management & profiles
    - Roles & permissions
    - Authentication
    - APIs

    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/laravel-users){ .md-button }

-   :material-shield-account-outline:{ .lg } **Keycloak Laravel Auth**

    ---

    <span class="bh-tag bh-tag--live">Documented</span>

    Complete Keycloak integration for Laravel 11, 12 and 13.

    - Browser SSO with PKCE & silent refresh
    - Offline-verified JWT API guard
    - Roles, scopes, groups & UMA permissions
    - Service tokens & full Admin API client

    [:octicons-book-24: Read the docs](../packages/keycloak-laravel-auth/index.md){ .md-button .md-button--primary }
    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/keycloak-laravel-auth){ .md-button }

-   :material-format-list-bulleted-type:{ .lg } **Laravel Dynamic Enums**

    ---

    Manage enum-style lookup values dynamically instead of hard-coding them.

    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/laravel-dynamic-enums){ .md-button }

-   :material-rocket-launch-outline:{ .lg } **Laravel Ready**

    ---

    A starter to manage identity, users, RBAC, dynamic enums and more for fresh Laravel
    applications.

    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/bhry98-laravel-ready){ .md-button }

-   :material-microsoft-azure:{ .lg } **Laravel Azure Connect**

    ---

    A Laravel package to integrate with and manage Azure Active Directory (Microsoft Entra ID)
    resources.

    [:fontawesome-brands-github: GitHub](https://github.com/bhry98/Laravel-Azure-Connect){ .md-button }
